# MotoGP_Calendar_Optimization
A numerical optimisation project, I  modelled the 2025 MotoGP calendar in Python and used Simulated Annealing, Genetic Algorithms, and Particle Swarm Optimisation to cut team travel distance from a 146,000km baseline into the 100,000-130,000km range, while keeping race temperatures within a safe 15-35°C limit.
